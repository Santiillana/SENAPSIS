# Competencias

- Agrega una competencia en `src/content/ficha.js` con un `id` estable; no uses su nombre como identificador.
- Define `tipo` (`principal` o `transversal`), `orden`, `activa`, `forma` y, si aparece en Aprende, `enAprende: true`.
- Asigna su referencia `token`; declara `--competence-<token>-solid`, `-tint`, `-border` y `-text` en `src/styles/tokens.css` para ambos temas.
- Asocia cada tema, clase, actividad y recurso mediante `competenciaId`.
- El emblema muestra una forma junto con el nombre; el color nunca comunica por sí solo.
- No se encontró una regla de color por género del instructor ni un campo de género. El horario colorea cada clase por competencia; no se introduce otra regla.
- Las dos competencias históricas `logica-programacion` y `competencia-por-configurar` siguen sin equivalencia confirmada en el catálogo de Aprende y conservan su color anterior.
